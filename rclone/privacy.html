Privacy policy

Last updated: 17 November 2026

"rclone personal backup" is a personal OAuth client used only by its owner to run rclone on their own computer.

  • What it accesses: files in the owner's own Google Drive, only when the owner runs rclone.
  • Where data goes: directly between the owner's computer and Google Drive. No server operated by this app receives, stores or logs any data.
  • Sharing: no data is sold, shared or given to anyone.
  • Google user data is used only to copy and sync the owner's files, in line with the Google API Services User Data Policy.
  • Removing access: revoke it any time at myaccount.google.com/permissions.
